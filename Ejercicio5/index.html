Interceptor de Peticiones y Manejo de Estado Offline

Esta aplicación demuestra la interceptación de peticiones HTTP en el Service Worker mediante el evento fetch. Al detectar la pérdida de conexión a internet o un error de red, si el recurso solicitado no existe en la Cache API, el Service Worker programa y entrega automáticamente una respuesta alternativa (fallback) renderizando la plantilla HTML personalizada de "Modo Sin Conexión".

⚡
Evento Fetch
Intercepción transparente de todas las peticiones salientes HTTP/HTTPS.
🌐
Detección de Pérdida de Red
Detección automática del fallo de red (Network Error / Offline).
📄
HTML Fallback Template
Renderizado dinámico de offline.html con minijuego e información técnica.
💾
Cache Strategy
Intento primario en Red/Caché y degradación progresiva limpia.

¿Cómo Simular la Pérdida de Conexión?

1. Usando Chrome / Edge / Firefox DevTools:
Presiona F12 o Ctrl + Shift + I, ve a la pestaña Network (Red) o Application > Service Workers, y marca la casilla Offline (Sin conexión).
2. Probar la Intercepción Fallback:
Una vez estando en Offline, haz clic en el botón "Navegar a URL Inexistente" o intenta refrescar la página. El Service Worker devolverá la plantilla offline.html personalizada.
