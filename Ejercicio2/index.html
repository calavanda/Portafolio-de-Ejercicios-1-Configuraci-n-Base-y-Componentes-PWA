App Shell / Arquitectura Base

Maquetado del App Shell

El modelo App Shell separa la infraestructura visual estática (Header, Navegación y Contenedor) del contenido dinámico, permitiendo tiempos de carga instantáneos y soporte offline garantizado.

Persistente

1. Header Fijo / App Bar

Provee la identidad visual corporativa, accesibilidad a acciones globales (instalación PWA, tema oscuro/claro) y botón de despliegue para móviles. Permanece fijo mediante backdrop-filter.

Adaptable

2. Menú de Navegación

Responsivo y dual: En pantallas grandes actúa como Sidebar lateral fijo, mientras que en pantallas pequeñas se transforma en un Off-canvas Drawer con backdrop y una barra inferior táctil.

Dinámico

3. Contenedor Principal

Área de renderizado reactiva identificada como <main>. Aloja los módulos y componentes sin necesidad de recargar la estructura base de la aplicación.

PWA / Splash Screen Nativa

Splash Screen Nativa en PWA

A diferencia de pantallas de carga simuladas con JavaScript, la Splash Screen nativa es generada por el propio sistema operativo y navegador (Chrome/Android/Desktop) inmediatamente al tocar el icono de la aplicación instalada.

Requisitos del Manifest para la Splash Screen

Chrome genera automáticamente la pantalla de bienvenida nativa combinando estas claves del archivo manifest.json:

{ "name": "App Shell & Splash PWA", "short_name": "AppShell", "start_url": "./index.html", "display": "standalone", "background_color": "#0f172a", /* Fondo de la Splash Screen */ "theme_color": "#6366f1", /* Barra de estado superior */ "icons": [ { "src": "./icons/icon-512.png", "sizes": "512x512", "type": "image/png" /* Icono central centrado */ } ] }

¿Cómo Funciona el Ciclo de Vida?

  • 1
    Toque en el Icono de Inicio:
    El SO levanta la ventana nativa y pinta background_color instantáneamente (0ms).
  • 2
    Carga del App Shell:
    El Service Worker sirve el App Shell desde la caché local sin esperar red.
  • 3
    Transición Suave al Shell:
    Una vez pintado el primer fotograma del App Shell, la splash screen nativa se desvanece fluidamente.

Guía Práctica / Verificación Chrome DevTools

Verificación en Chrome DevTools

Sigue estos pasos directos en las Herramientas de Desarrollo de Chrome para validar que el navegador detectó la Splash Screen nativa y que la aplicación cumple con todos los criterios de instalación.

1

Abrir Chrome DevTools

Presiona la tecla F12 o la combinación Ctrl + Shift + I (o Cmd + Option + I en macOS) en esta misma pestaña.

2

Navegar a la Pestaña "Application" (Aplicación)

En la barra superior de DevTools, localiza y selecciona la pestaña Application. En el panel lateral izquierdo, bajo la categoría Application, haz clic en Manifest.

3

Inspeccionar la Vista Previa de "Splash screen"

Desplázate hacia abajo en el panel del Manifest. Verás dos recuadros visuales generados automáticamente por Chrome:

  • Presentation: Muestra el icono en la pantalla de inicio con su nombre.
  • Splash screen: Muestra exactamente el fondo #0f172a con el icono centrado de 512x512 y el color del tema #6366f1.
4

Simular la Instalación y Criterios de PWA

En la parte superior del panel Manifest en DevTools, haz clic en el enlace "Install app" o "Simulate install event". También puedes hacer clic en el botón superior de esta barra:

5

Simular Dispositivo Móvil para ver la Splash Screen en Acción

Activa el modo de dispositivo en DevTools (Ctrl + Shift + M) seleccionando un dispositivo como "Pixel 7" o "Samsung Galaxy". Al instalar la PWA y abrirla en una ventana independiente, Chrome mostrará la Splash Screen nativa antes de renderizar el App Shell.
