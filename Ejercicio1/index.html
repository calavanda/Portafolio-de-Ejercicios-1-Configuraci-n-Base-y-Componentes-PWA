Archivo

manifest.json

El manifiesto es el corazón de una PWA. Define cómo se comporta la aplicación cuando se instala en el dispositivo del usuario.

manifest.json 
{
  "name": "PWA Ejercicio App",
  "short_name": "PWAApp",
  "description": "Aplicación web progresiva de ejemplo...",
  "start_url": "/index.html",
  "display": "standalone",
  "orientation": "any",
  "theme_color": "#4F46E5",
  "background_color": "#0F0E1A",
  "lang": "es",
  "scope": "/",
  "icons": [
    {
      "src": "icons/icon-192x192.png",
      "sizes": "192x192",
      "type": "image/png",
      "purpose": "any maskable"
    },
    {
      "src": "icons/icon-512x512.png",
      "sizes": "512x512",
      "type": "image/png",
      "purpose": "any maskable"
    }
  ]
}
Configuración

Propiedades Clave

Cada propiedad del manifest tiene un propósito específico para la experiencia de instalación.

name

Nombre completo de la aplicación. Aparece en la pantalla de instalación y en la lista de aplicaciones del sistema.

"PWA Ejercicio App"
short_name

Nombre corto usado en la pantalla de inicio cuando el espacio es limitado (ej. bajo el ícono en Android/iOS).

"PWAApp"
start_url

URL que se abre cuando el usuario lanza la aplicación instalada. Define el punto de entrada de la app.

"/index.html"
display

standalone: La app se muestra como una aplicación nativa, sin barra de URL del navegador. Experiencia de app completa.

"standalone"
theme_color

Color que colorea la barra de estado del sistema operativo y la barra de tareas cuando la app está abierta.

"#4F46E5"
background_color

Color de fondo mostrado en la splash screen mientras la app se carga por primera vez después de instalada.

"#0F0E1A"
Assets

Paquete de Iconos

Los iconos PNG son esenciales para la instalación. Se requieren al menos dos tamaños estándar.

192 × 192 Ícono estándar

Usado en la pantalla de inicio, cajón de aplicaciones y notificaciones de Android.

PNG any maskable
512 × 512 Ícono de alta resolución

Requerido por Chrome para la pantalla de bienvenida (splash screen) al instalar la PWA.

PNG any maskable
